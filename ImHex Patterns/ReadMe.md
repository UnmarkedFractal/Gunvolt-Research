Pattern files for use with [ImHex](https://imhex.werwolv.net/).

File Types:
- [OSB](ImHex_Patterns/OSB.hexpat) => Sprites, Shaders & Animations(?). For GV3, IX2 & GVTE decrypted files that start with the bytes `6C 00 00 00 00 00 00 00`. The extension comes from some referenced file names in other files.
- [EvList](ImHex_Patterns/EvList.hexpa) => Event (Cutscene?) List. `*.evlist` files in the `Event` folder.
- OTF => Standard OpenType font files. For decrypted files starting with the bytes `OTFO`.
